# Help

**The visualization has not appeared.** Some of these stream genomic data over the network and
take a few seconds. If nothing appears after roughly 15 seconds, and there is no error message
either, use the **"Cannot evaluate: technical problems with the interface"** option.

**The visualization shows an error message.** That is a property of the output, not a tooling
problem. Rate it **1**.

**I do not understand the request.** Rate what you can. If you cannot assess a particular aspect
in the follow-up, tick "Cannot assess" for that row.

**I do not know this data type.** That is fine and expected. Several of these are outside any
one person's area. Judge what you can see, and use "Cannot assess" in the follow-up.

**I need to stop.** Close the tab. Everything you have submitted so far is saved. Please email
us so we can reassign the rest.
